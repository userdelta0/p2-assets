# Faith plate (Portal 2 "catapult") manifest.
#
# ONE RECORD PER LINE, whitespace-separated, read with a plain find("%S+") tokenizer. StarfallEx
# caps the SUBJECT LENGTH of a pattern search (~15000 chars), so the chip also splits lines with a
# plain string.find(s, "\n", pos, true) rather than a gmatch. Never rewrite either as a fancy
# multi-capture pattern - it will work on this file and then die on a bigger one.
#
# Blank lines and lines starting with # are skipped. First token = record type.
#
# ---------------------------------------------------------------------------------------------
# WHERE THIS CAME FROM (verified against retail Portal 2, not guessed):
#   small  models/props/faith_plate.mdl      MDL v49, 23 bones, 4 sequences, 2 skin families
#   large  models/props/faith_plate_128.mdl  MDL v49, 39 bones, 2 sequences, 1 skin family
#          The large panel is a TRIPLE plate - three mechanisms side by side at x = -38, 0, +38.
#
#   There is NO prop_faith_plate entity in retail P2 (internally it is called Catapult). The plate
#   is a prop_dynamic with DefaultAnim "idle" and solid 0; the launch is a trigger_catapult, and
#   three logic_relays fire PlaySound + SetAnimation together:
#       relay_normal -> angled     relay_fast -> fast     relay_up -> straightup
#   sound: ambient_generic "Metal_SeafloorCar.BulletImpact" -> doors/heavy_metal_stop1.wav
#          CHAN_AUTO, SNDLVL_NORM, volume 0.70, ambient_generic radius 1250
#
# MODEL ORIENTATION - measured from the OBJ vertex bounds, NOT assumed:
#   Both plates are authored as WALL PANELS whose FACE NORMAL IS MODEL +Y. The Y extent is the
#   thin one (about 61u) against 64x128 for the small plate and 128x162 for the large. A chip that
#   assumes the usual +Z up will lay them on their side.
# ---------------------------------------------------------------------------------------------
#
# model <id> <obj> <anims>
#   Selects a whole plate. Every "part" record after it belongs to that model until the next one.
#
# part <id> <tex> <px> <py> <pz> <bone>
#   One rigid piece. All of a model's parts live in the SAME obj: mesh.createFromObj returns a
#   table keyed by these ids, so the chip loads the file once and indexes it. Meshes are in MODEL
#   space (shared origin); <px py pz> is that piece's BONE PIVOT in the same space - rotate the
#   piece about its pivot to animate it. <bone> names the track that drives it ("-" = static).
#   NOTE the small plate's part ids are GROUP names chosen at split time, so the bone they follow
#   is spelled out here; the large plate's ids are the bone names themselves.

#   is shared). The large plate has only one family, so "error" simply does not apply to it.

# anim <id> <fps> <frames> <looping>
#   Curves live in each model's anims file - flat whitespace records, because the chip receives
#   these as a STRING from the zip and StarfallEx has no loadstring to evaluate a .lua table.
#   Per-frame LOCAL bone deltas vs bind pose: pos = {x,y,z} units, rot = {p,y,r} degrees in GMod
#   Angle order. The small plate has all three launch clips; the large one only has straightup.

anim angled     30  99  0
anim straightup 30  99  0
anim fast       24  15  0
